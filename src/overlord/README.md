# 진삼국무쌍 오버로드 리소스 연구실

`npm run dev`로 실행 후 `/overlord.html`을 엽니다. 기존 `/`의 조운 연무장은 별도 화면입니다.

## 맵 메이커

- **원작 3D 장면**: `public/overlord/scenes/manifest.json`에 변환된 장면을 선택합니다. 원본 정적 메시·계층·변환을 보여주며 Unity 전용 셰이더·파티클·조명·게임 로직은 재현 범위에 포함되지 않습니다.
- **해석한 맵 배치**: `public/overlord/maps/index.json`의 맵 파일을 엽니다. 원본 protobuf 좌표의 배치 마커와 연결 후보인 높이 격자를 보여줍니다. 마커는 실제 지물 모델을 대신하는 참조 표현입니다. 지형 연결은 파일명 일치 근거이며 높이·격자 좌표 일부 해석은 정적 추론입니다.
- **맵 파일 전체**: APK 명세의 파일명을 찾습니다. 파일명 목록은 원작 전체 콘텐츠나 변환 완료를 보증하지 않습니다.
- **원본 영역 코드 격자**: `.Area`의 원시 코드 0/1/2/3을 색으로 구분합니다. 높이 격자에 최근접 투영한 분석용 표시이며 이동·전투 가능 영역 같은 게임 의미는 확인되지 않았습니다. 배치 맵에 대응 영역이 있으면 `영역 코드` 레이어로 켤 수도 있습니다.
- 전체 보기·평면 보기·입체 보기, 와이어, 격자, 지형/지물/컴포넌트 표시를 지원합니다.
- 원작 장면의 초기 표시 레이어는 노드 이름의 Terrain/skybox/Collider 규칙으로 구분한 시각적 분류입니다. 원작 런타임의 레이어 의미로 확정한 분류가 아니며 편집기에서 바꿀 수 있습니다. 하늘·충돌 디버그는 초기 숨김이며 원본 inactive/rendererEnabled 값도 존중합니다.
- 장면 계층에서 오브젝트를 선택해 위치·회전·크기·레이어·표시 여부를 편집합니다. 큰 장면은 앞 300개만 표시되며 검색은 전체 계층에서 수행합니다.
- 장면 저장/열기는 Three.js 메시·재질·계층·편집값·클립을 포함한 연구실 JSON을 사용합니다. 원작 데이터 형식으로 재패킹하는 기능은 아닙니다.

## 모션 체커

- 캐릭터 변환 명세 `public/overlord/assets/characters/manifest.json`에서 실제 스킨 모델과 클립을 불러옵니다. 변환되지 않은 항목은 파일명 후보로 구분합니다.
- 클립 선택, 재생/정지, 타임라인 탐색, 1/30초 단위 이동, 재생 속도, 반복을 지원합니다.
- 원본 테이블에 연결 정보가 있는 캐릭터는 공격·스킬 슬롯이 자동 연결됩니다. J는 A 공격 연계를 따라가며, U는 B 차지, O는 A→B 차지 경로를 순서대로 보여줍니다. 스킬 슬롯 1·2는 이 두 차지 분기의 미리보기이며 원작의 독립 액티브 버튼 2개를 뜻하지 않습니다. 해금·타격 판정·취소 가능 시간은 시뮬레이션하지 않습니다.
- 슬롯의 클립을 직접 바꾸면 사용자 지정 재생으로 전환됩니다. 연결 정보가 없는 캐릭터도 전체 클립 목록에서 재생할 수 있습니다.
- 콤보 클립을 `+`로 추가한 뒤 순서대로 재생합니다. 이 순서는 사용자가 구성하는 검사 목록이며 원작의 공격 전이·입력 창·히트 판정을 복원한 전투 시스템은 아닙니다.
- 원본 루트 모션·이벤트·일부 비변환 바인딩·별도 무기/이펙트는 캐릭터별 변환 보고서의 제한을 확인하세요.

## 자체 파일 가져오기

GLB 또는 glTF를 가져오거나 캔버스에 놓을 수 있습니다. glTF는 `.bin`·텍스처를 함께 선택합니다. 파일은 브라우저 안에서 처리합니다. 외부 URL 의존성을 자동 다운로드하지 않으며 누락된 동반 파일은 오류를 표시합니다.

로컬 작업이므로 원본 APK와 추출 파일은 별도 `reference/overlord`에 보존됩니다. 화면의 편집은 브라우저 작업 장면에 적용되며 장면 저장으로 내보낼 수 있습니다.

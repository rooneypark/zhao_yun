# 조운 모델링 최종 시안 v2

2026-11-06 확정. 투구 없는 검은 머리 조운, 은색 찰갑, 파란 목도리, 남보라 의상, 흰 탈착형 망토를 기준으로 한다. 이전 v1은 폐기한다.

## 입력 파일

| 작업 | 파일 | 기준 |
|---|---|---|
| 캐릭터 정면 | `01-character/01-front.png` | 외형·비율 최우선 기준 |
| 캐릭터 왼쪽 | `01-character/02-left-plain.png` | 캐릭터 자신의 왼쪽, 일반 찰갑 어깨 |
| 캐릭터 후면 | `01-character/03-back.png` | 등 갑옷과 망토 고정점 |
| 캐릭터 오른쪽 | `01-character/04-right-beast.png` | 캐릭터 자신의 오른쪽, 은색 맹수 어깨 |
| 창 | `02-weapon/spear-front.png` | 별도 소품 생성 |
| 망토 | `03-cape/cape-rear.png` | 별도 소품 제작, 바깥 뒷면 |

좌우는 보는 사람의 좌우가 아니다. 정면 이미지에서 맹수 어깨는 화면 왼쪽에 있다.

## Tripo와 Blender 작업

1. 캐릭터 4장을 하나의 멀티뷰 입력으로 사용한다. 몸체에는 무기·망토가 없으며 중립 A포즈이다.
2. 창과 망토는 별도 작업으로 만든다. 캐릭터의 추가 방향으로 입력하지 않는다.
3. 망토의 두 고리는 목도리 뒤쪽, 어깨 갑옷 안쪽의 두 은색 고정점에 연결한다. 몸 앞을 감싸는 흰 천은 없다.
4. 조립 시 망토 길이는 등 상단에서 무릎 위까지 맞춘다. 서로 다른 이미지의 픽셀 크기가 실제 조립 크기를 뜻하지 않는다.
5. 망토는 얇은 천이므로 생성 결과를 확인하고 필요하면 Blender에서 별도 메시로 제작한다. 망토 뼈대·웨이트·동작은 몸체 모션과 별도로 설정한다.
6. 텍스처 포함 GLB를 받아 스키닝과 오버로드 조운 모션 적용을 시험한다. 첫 검증은 대기·달리기·기본 공격 1개다.

## 검수 범위와 한계

각 이미지는 built-in image_gen으로 생성했으며 전신 잘림, 무기/망토 분리, 좌우 비대칭 배치, 배경과 기본 자세를 육안 확인했다. 6개 PNG 파일의 디코딩과 해상도도 확인했다. 실제 Tripo 생성 검증은 아직 하지 않았다.

동일 3D 메시에서 렌더링한 정투영 도면은 아니다. 방향별 머리카락, 손가락, 갑옷 조각 수·문양·두께에는 차이가 남을 수 있다. 측면은 A포즈의 팔·다리가 겹치는 방향이다. 충돌하는 세부 사항은 정면 기준으로 정리하고, 새 모델의 관절 변형과 실루엣을 확인한다. 가려져 있던 등 구조는 이번에 보완 설계했다. 창과 망토의 측면/안쪽 이미지는 포함하지 않는다.

착용·인게임 연출 시안은 멀티뷰 생성 입력에 섞지 않는다. 프롬프트는 `prompts.txt`에 보관한다.
